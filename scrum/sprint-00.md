# Sprint 00 — 구현에서 개발 지침과 Spec 복원

> **실행 보드:** [`../TODO.md`](../TODO.md)

## 스프린트 목표

Theia IDE Boilerplate 저장소의 구현을 먼저 조사하여 루트 `AGENTS.md`를 복원하고, 그 구현에서 요구사항과 Spec을 역추출한다. 이후 SDD의 PRD → AC 식별 → AC 검토 → ASR 통합 → Spec 작성 → Spec 검토를 완료하고, 확정된 Spec을 기반으로 제품 백로그를 생성한 뒤 이미 구현된 코드와의 일치 여부를 검증한다.

## 완료 정의

1. 저장소의 루트 구조, 애플리케이션/확장 모듈, 주요 설정과 작업 흐름이 구현 사실에 근거해 `AGENTS.md`에 설명되어 있다.
2. SDD의 PRD, AC, ASR, 최종 Spec, Spec 검토 기록이 사용자 승인 상태로 작성되어 있다.
3. 확정된 Spec의 요구사항이 제품 백로그의 `PB-*` 스토리로 기록되고, 이번 스프린트에서 이미 구현된 것으로 완료 처리되어 있다.
4. Spec과 구현의 일치 여부를 빌드·린트·테스트 또는 문서/설정 대조로 검증하고 검증 기록을 남긴다.
5. 설치·개발 빌드·프로덕션 빌드·패키징·테스트·린트·브라우저 실행 명령이 실제 `package.json` 및 README와 일치한다.
